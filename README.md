## What it does

`main.ts` writes one short account — one or two sentences, no more than 400 characters — of the silliest time an AI coding agent misunderstood what it was asked and wrecked the code it was given, to `/output/entry.txt`. The entry is validated against the competition gate (1–400 characters, not only whitespace) before it is written.

## Run

```sh
node main.ts
```
